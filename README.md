# Personal Calendar — локальна версія

Персональний календар консультацій для iPhone. Немає Supabase, бази даних, логіна, пароля, API-ключів або серверної частини.

## Як це працює

- Записи зберігаються в IndexedDB браузера на цьому пристрої.
- Календар розміщується на Vercel як статичний сайт.
- PWA можна додати на головний екран iPhone.
- Часові пояси: `Asia/Tbilisi`, `Europe/Kyiv`, `Europe/Warsaw`.
- Місяць / тиждень / день / список; drag-and-drop; редагування та видалення.
- Є експорт та імпорт резервної копії JSON.

## Важливі обмеження

1. **Дані локальні.** Вони не синхронізуються з іншим телефоном або комп'ютером. Очищення даних Safari, видалення даних сайту або проблеми з пристроєм можуть призвести до втрати записів. Регулярно експортуй резервну копію.
2. **Нагадування.** Браузерні сповіщення можуть показуватися, коли календар відкритий і браузер активний. Без сервера, push-служби або нативного застосунку не можна надійно запланувати доставку сповіщення, коли PWA закрита. Не покладайся на них як на єдине нагадування.
3. **Перший запуск потребує інтернету.** Після завантаження оболонка сайту кешується для наступного відкриття; залежності FullCalendar завантажуються в складі збірки.

## Розгортання на Vercel

1. Розпакуй ZIP.
2. Завантаж усі файли у GitHub repository (можна зробити приватний).
3. У Vercel обери Add New → Project і імпортуй репозиторій.
4. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.
5. Жодних Environment Variables не потрібно.
6. Натисни Deploy.

## Встановлення на iPhone

1. Відкрий адресу Vercel у Safari.
2. Share → Add to Home Screen → Add.
3. Запускай календар з нової іконки.
4. Для резервної копії натискай іконку завантаження; для відновлення — іконку імпорту та обери JSON-файл.

## Резервне копіювання

Експортуй JSON після кожної важливої зміни або хоча б раз на тиждень. Зберігай копію в iCloud Drive або іншому безпечному місці.
